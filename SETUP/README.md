# Savannah Health System — local hospital setup

Use this folder from the project working directory to install and run the system on an office laptop.

## Steps

1. Install **XAMPP**, **Composer**, and **Node.js LTS**
2. Start **MySQL** in XAMPP
3. Run `1-INSTALL.bat` once
4. Run `2-START.bat` each day
5. Optional: `3-OPEN-BROWSER.bat`

## Login

| Field | Value |
|---|---|
| Email | `admin@savannah.health` |
| Password | `Savannah@Admin1` |

Register other hospital workers under **Staff Users**.
